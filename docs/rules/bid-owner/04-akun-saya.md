# Akun Saya

- Untuk bid owner yang pertama kali login (setelah akun aktif), muncul notif “Selamat datang di PHBID”
- Apabila akun bid owner dinonaktifkan , maka akses yang dimiliki oleh bid owner hanya akun saya dan muncul notif  “Akun anda dinonaktifkan”
- NPWP dan SIUP yang telah diupload, bisa di download kembali oleh bid owner di halaman akun sayaBerlaku juga untuk identitas dan logo perusahaan
- yang telah diupload. Bisa download kembali
- Di sisi bid owner, Beranda pada breadcrumb diarahkan ke halaman cari penawaran
- Apabila saat edit akun saya, akan diganti dengan nomor WA yang sudah digunakan oleh akun lain (termasuk sub user) maka muncul alert “Nomor whatsapp sudah terdaftar di sistem”
- Ketika bid owner aktif melakukan perubahan pada data akun saya maka perlu konfirmasi dari admin sehingga data akun yang diubah tidak otomatis terganti.
- Ketika perubahan data akun saya belum dikonfirmasi admin maka bid owner tidak dapat mengedit akun saya kembali (tombol edit akun saya disable)
- Ketika admin validasi terima perubahan data maka data pada akun saya akan terganti sesuai data yang diubah sebelumnya dan tombol edit akun saya aktif kembali
- Ketika admin tolak perubahan data maka data akun bid owner tetap tidak terganti dan bid owner dapat mengedit akun saya kembali (tombol edit akun saya aktif kembali)
- Ketika admin terima ataupun tolak perubahan data akun saya bid owner maka bid owner akan mendapatkan notif email perubahan data diterima ataupun perubahan data ditolak
