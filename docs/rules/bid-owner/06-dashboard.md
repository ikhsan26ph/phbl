# Dashboard

## Monitoring Pengiriman

  - Data masuk atau tampil pada dashboard monitoring pengiriman Ketika pesanan sudah input unit atau statusnya “Proses Penugasan” sampai dengan “Order Selesai”
  - Pilihan tanggal dashboard order maksimal 90 hari, lebih dari 90 hari tidak bisa
  - Dashboard monitoring pengiriman dapat ditampilkan layar penuh dengan mengklik “Tampilkan Penuh”
  - Jika dashboard monitoring pengiriman sudah ditampilkan layar penuh maka terdapat tombol “Tutup”, jika diklik maka menutup tampilan layar penuh dashboard monitoring pengiriman
  - Pada dashboard monitoring pengiriman terdapat fitur export excel. Jika klik export excel akan mendownload file excel sesuai data yang ditampilkan berdasarkan hasil filter
  - Data pesanan yang ditampilkan pada dashboard monitoring pengiriman mengalami pembaruan yaitu id order, consignee, alamat tujuan, nomor referensi, nama kapal, stuffing, etd, eta, kapal sandar, dooring, bidder, pelabuhan tujuan
  - Nama consignee yang ditampilkan ialah nama perusahaan penerima barang
  - Tanggal stuffing yang ditampilkan per order. Data stuffing paling baru
  - Jika pada order ada lebih dari 1 unit maka tanggal stuffing yang ditampilkan ialah tanggal stuffing terbaru dari beberapa unit tersebut
  - Sedangkan pada dooring tanggal tracking yang ditampilkan per unitnya.
  - Jika pesanan belum dilakukan tracking stuffing, kapal sandar dan dooring maka ditampilkan tanda strip
  - Jika id order diklik akan diarahkan ke halaman detail pesanan (open new tab) bagian status pengiriman
  - Kolom id order, stuffing, etd, eta, kapal sandar, bidder, Pelabuhan tujuan terdapat tombol sortirnya sehingga bisa diurutkan datanya
  - Jika terdapat data pesanan baru yang telah input unit maka dashboard order dapat auto update
  - Jika ada perubahan pada jadwal maupun tanggal tracking stuffing, kapal sandar, dooring maka data order pada dashboard monitoring pengiriman dapat langsung auto update tanpa perlu merefresh halaman

## Frekuensi Pengiriman

  - Data yang tampil pada dashboard frekuensi pengiriman ialah data jumlah pesanan yang sudah diinputkan unitnya atau statusnya “Proses Penugasan” sampai dengan “Order Selesai”
  - Pilihan tanggal dashboard frekuensi pengiriman maksimal 90 hari, lebih dari 90 hari tidak bisa
  - Pada dashboard frekuensi pengiriman ditampilkan tampilan map Indonesia dan terdapat penanda lokasi pada mapnya yang menunjukkan rute tujuan pesanan yang telah diinputkan unitnya
  - Jika lokasinya diklik akan menampilkan jumlah pesanan / pengiriman dan persentasenya dari seluruh pesananan yang telah diinputkan unitnya
  - Tampilan mapnya dapat di zoom in maupun zoom out
  - Tampilan dashboard frekuensi pengiriman dapat ditampilkan layar penuh dengan mengklik textlink “Tampilkan Penuh’
  - Jika dashboard frekuensi pengiriman sudah ditampilkan layar penuh maka terdapat textlink “Tutup”, jika diklik maka menutup tampilan layar penuh dashboard frekuensi pengiriman
  - Jika tidak ada data yang ditampilkan maka hanya tampil map Indonesia tanpa ada penanda lokasi kota tujuan
  - Jika terdapat data pesanan baru yang telah input unit maka dashboard frekuensi pengiriman dapat auto update

## Grafik Pengiriman

  - Data yang tampil pada dashboard grafik pengiriman ialah data jumlah pesanan yang sudah diinputkan unitnya atau statusnya “Proses Penugasan” sampai dengan “Order Selesai”
  - Pilihan tanggal dashboard grafik pengiriman maksimal 90 hari, lebih dari 90 hari tidak bisa
  - Pada dashboard grafik pengiriman ditampilkan diagram batang jumlah pengiriman / pesanan pada kota tujuan pesanan tersebut
  - Tampilan dashboard grafik pengiriman dapat ditampilkan layar penuh dengan mengklik textlink “Tampilkan Penuh’
  - Jika dashboard grafik pengiriman sudah ditampilkan layar penuh maka terdapat textlink “Tutup”, jika diklik maka menutup tampilan layar penuh dashboard grafik pengiriman
  - Jika tidak ada data yang ditampilkan maka diagram batangnya juga tidak tampil
  - Jika terdapat data pesanan baru yang telah input unit maka dashboard grafik pengiriman dapat auto refresh
